ตัวอย่างแถวที่กรอกจำนวนแล้ว

🏷️ หมวดสีรายการวัตถุดิบ

ตั้งชื่อหมวดและเลือกสีได้เอง แล้วไปหน้าสต๊อกหรือหน้าเช็กของใกล้หมด เลือกสีหมวดแล้วแตะรายการเพื่อลงสี · เปลี่ยนสีหมวดที่นี่ ทุกรายการในหมวดจะเปลี่ยนตามอัตโนมัติ

↕️ การจัดเรียงรายการ

หน้าสต๊อกและหน้าเช็กของใกล้หมด: แตะไอคอน ☰ หน้าแถวค้างไว้แล้วลากขึ้น–ลงเพื่อเรียงใหม่ (หน้าสต๊อกมีปุ่ม ↑ ↓ สำรอง) · มีปุ่ม “เรียงรายการตามหมวดสี” ในหน้าสต๊อก · ลำดับจะถูกบันทึกและซิงค์อัตโนมัติ

🛡️ ข้อมูลและความเป็นส่วนตัว

ข้อมูลสูตรและสต๊อกเก็บในเครื่องผ่าน localStorage และจะซิงค์ไป Firebase เฉพาะเมื่อเปิดใช้งานการซิงค์ หากใช้ AI OCR โดยใส่ API key ในเว็บ คีย์อาจถูกเข้าถึงได้จากผู้ที่เข้าถึงอุปกรณ์หรือโค้ดหน้าเว็บ ไม่ควรใช้คีย์ที่มีสิทธิ์กว้างหรือแชร์ไฟล์แอปพร้อมคีย์

📋 ใช้ข้อความที่สแกนจากมือถือ (Xiaomi/POCO, Google Lens)

1) เปิดรูปสมุดในแกลลอรี่ แล้วใช้ฟังก์ชันดึง/คัดลอกข้อความของเครื่อง (หรือ Google Lens) → คัดลอก
2) กลับมาที่แอพ แตะค้างในช่องด้านล่าง เลือก "วาง"
3) กด "แปลงเป็นรายการ" แล้วตรวจแก้ได้เลย

⚙️ ตัวอ่านข้อความ

API key เก็บไว้ในเครื่องนี้เท่านั้น และต้องต่ออินเทอร์เน็ตตอนสแกน

👆 ลากมุมทั้งสี่ เพื่อตัดให้เหลือเฉพาะรายการวัตถุดิบ หรือลากกลางกรอบเพื่อย้าย
☁️ ซิงค์สูตรกับทีม (หลายเครื่อง)

ยังไม่ได้เชื่อมต่อ

📖 วิธีตั้งค่า Firebase (ทำครั้งเดียว)
  1. เข้า console.firebase.google.com ล็อกอินด้วยบัญชี Google แล้วสร้างโปรเจกต์ใหม่ (ปิด Analytics ได้)
  2. เมนู Build → Realtime Database → Create Database เลือกที่ตั้ง เช่น สิงคโปร์ และเริ่มแบบ locked mode
  3. แท็บ Rules ลบของเดิม วางโค้ดนี้ แล้วกด Publish 
    {
  "rules": {
    "teams": {
      "$team": { ".read": true, ".write": true }
    }
  }
}
  4. แท็บ Data คัดลอกที่อยู่ขึ้นต้น https:// ด้านบน มาวางในช่อง Database URL
  5. ตั้งรหัสทีม ใช้รหัสเดียวกันทุกเครื่อง แล้วกด "เชื่อมต่อ"

ใครรู้รหัสทีมจะอ่านและแก้สูตรได้ จึงไม่ควรบอกคนนอก ชื่อเมนูใน Firebase อาจต่างจากนี้เล็กน้อย
